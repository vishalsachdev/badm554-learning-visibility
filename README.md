# Making Student Reasoning Visible

A course case study from BADM 554 at Gies College of Business: how it makes student reasoning visible with GitHub, AI-assisted review and Canvas, what the course records show, and what they do not show yet. By Vishal Sachdev.

- `docs/index.html`: the findings, with the NotebookLM audio overview, captions and transcript.
- `docs/process.html`: how the page was built (chat sessions, git logs, course records, Codex Edu privacy check, command-line tools, NotebookLM).
- `docs/site.css`, `docs/assets/`: shared styles, audio (MP3), captions (VTT) and transcript (TXT).

The site is static HTML with no JavaScript. GitHub Pages serves it from `docs/` once the repository is public.

Plan: [plan-as-approved.md](plan-as-approved.md). Audio overview generated by Google NotebookLM from the reviewed report.
